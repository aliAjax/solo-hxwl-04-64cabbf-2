# hxwl-04 牙科根管治疗管理台

把静态看板改造成的可操作门诊治疗管理台：按患者建立多牙位根管疗程，管理阶段、工作长度、主尖锉、封药与下次复诊，月历排期、角色权限、操作记录与本地持久化全部在浏览器完成，无后端。

## 技术栈

React 19 + Vite 7 + TypeScript（严格模式）+ 原生 CSS，数据存 localStorage（键 `hxwl-rct-db-v1`）。

## 本地运行

```bash
npm install
npm run dev        # http://localhost:5104
```

构建与验证：

```bash
npm run build      # tsc 类型检查 + vite 生产构建
npm run verify     # 32 组领域规则断言 + 9 项 jsdom UI 交互冒烟
```

- `npm run verify:rules`：重复牙位、时间冲突、非法阶段跳转、必填门禁、三类角色权限、指标/筛选/导出同步、空库恢复、持久化。
- `npm run verify:ui`：jsdom 挂载完整 App，验证角色切换、列表筛选、阶段门禁逐环阻止与放行、材料登记、联系方式校验、日历双击排期、导出留痕、刷新（重挂载）不丢数据。

## 功能与规则

### 数据模型
- 患者（1）→（N）疗程：同一患者同一 FDI 牙位只允许一个疗程，重复建疗程会被阻止并指出当前阶段。
- 疗程：牙位、诊断、根管情况、工作长度、主尖锉、封药药物、充填材料、负责医生、下次复诊。
- 阶段固定顺序：开髓 → 测长 → 根管预备 → 封药 → 充填 → 完成。

### 拦截规则（弹窗行内错误 / Toast 均带中文原因）
- **重复牙位**：同患者同牙位禁止重复建档（`#36` 与 `36` 视为同一牙位；牙位校验 FDI 11–48）。
- **时间冲突**：同一医生或同一患者与既有复诊重叠（按分钟区间精确判断）；同疗程重复排期必须先取消或改期。
- **非法阶段跳转**：不能回退、不能跳级、完成后锁定；封药阶段允许"复诊换药"保持阶段不变。
- **必填门禁**：进测长需工作长度；进封药需主尖锉；进充填需封药药物；完成需充填材料；建疗程需患者/牙位/诊断/医生；排期需未来时间（10–480 分钟）与目的；电话 7–20 位数字。

### 角色权限（右上角切换身份，所有越权操作均被阻止）
- **医生**：只能修改/推进/排期自己负责的疗程；可改派医生（待赴约复诊同步改派）；只有医生能建疗程与改诊断。
- **助理**：可登记材料，不能改诊断/临床信息，不能排期。
- **前台**：只能排期/改期/取消复诊与修改患者联系方式。

### 随数据实时同步
- 指标：待复诊、逾复诊期、进行中、封药病例、已充填完成、平均工作长度（从"MB 19.5mm / DB 20mm"等文本自动提取取均值）。
- 筛选：阶段（带计数）、负责医生、关键字（患者/牙位/诊断/医生）、仅看逾期；导出 CSV **只含当前筛选结果**（UTF-8 BOM，Excel 直开），导出动作写操作记录。
- 月历：月视图、今日高亮、逾期/本人事件配色、双击空白日快速排期。
- 操作记录：全部动作（建档、改临床信息、推进、排期/改期/取消、材料、改电话、改派、导出、清空/恢复）留痕，含时间、角色、人、详情。

### 数据管理
- 全部数据仅存本浏览器，刷新不丢。
- 首次打开自动载入示例数据；空库页面可一键恢复示例；底部可清空或用示例覆盖（均二次确认）。
- 响应式：桌面三栏/详情双栏，平板指标 3 列，手机单列、步骤条折行、弹窗变为底部抽屉式、日历精简显示。
